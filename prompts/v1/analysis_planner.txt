Return a JSON object with key "steps" — a list of up to 5 analysis steps. Each step:
{
  "step_id": "step_1",
  "description": "Human-readable description of what this step does",
  "sub_query": "Specific analytical question this step answers",
  "requires_code": true
}

Rules:
- Steps must be ordered: simpler aggregations first, derived insights last
- Be specific about which columns each step uses
- If a step is narrative-only (no computation), set requires_code: false

Return only valid JSON. No markdown, no explanation.
